# FILM!

Афиша и заказ билетов: фронтенд (React + Vite), бэкенд (NestJS + PostgreSQL + TypeORM).

## Задеплоенное приложение

**Ссылка:** http://stanislav-film-production.nomorepartiessite.ru/

## Локальный запуск

### Бэкенд

```bash
cd backend
npm ci
npm run start:dev
```

### Фронтенд

```bash
cd frontend
npm ci
npm run dev
```
